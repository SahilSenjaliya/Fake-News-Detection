Machine Learning Architecture & Project Specs

Dataset & Cleaning

Evaluated on 44,898 raw news articles from True.csv and Fake.csv. Removed 209 exact duplicate entries before train/test splitting to prevent data contamination. Metadata features (subject, date) were strictly excluded to eliminate data leakage.
